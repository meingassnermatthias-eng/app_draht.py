# Donnerwetter – Hardrock für Bläser (Originalkomposition)

Besetzung: 2 Trompeten in B, Klarinette in B, Horn in F, Tenorhorn in B, Tuba, Schlagwerk ad lib.
Klingend d-Moll (Refrain F-Dur) · 4/4 · ♩ = 132 · ca. 1¾ Min.

| Teil | Takte | Was passiert |
|------|-------|--------------|
| Intro | 1–5 | Einzählen, Riff in Tuba + Tenorhorn, dann Stabs in Trompeten/Klarinette |
| Riff | 6–9 | Riff mit Power-Stabs und Rock-Groove |
| A | 10–17 | Thema Trp 1, 2. Stimme Trp 2, Klarinetten-Fills, Tuba-Achtel, Tenorhorn-Power-Rhythmus |
| Riff | 18–19 | |
| B | 20–27 | Refrain in F-Dur, Trp 1 + Klarinette Melodie, Ride-Becken |
| Solo | 28–35 | Klarinetten-Solo (16tel-Läufe, Triller, Blue Note), notiert bis E6 |
| Break | 36–39 | nur Tuba-Riff + Toms, Crescendo |
| A' | 40–47 | Thema, Klarinette eine Oktave höher |
| B' | 48–55 | Refrain ff, Klarinette 8va |
| Schluss | 56–59 | Riff tutti unisono, B – C – D-Schlussakkord mit Fermate |

Horn: absichtlich leicht – nur Haltetöne in der Mittellage (notiert D4–Gis4/H4).

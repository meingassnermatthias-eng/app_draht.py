# Heute gibt's ein Rehragout – Polka für Jungmusiker

Besetzung: 2 Tenorhörner in B (Violinschlüssel), Tuba in F · klingend B-Dur (Tenorhörner notiert C-Dur) · 2/4 · ♩ = 104 · ca. 1¼ Min.

| Teil | Takte | Was passiert |
|------|-------|--------------|
| Intro | 1–4 | Jagdsignal der Tenorhörner, Tuba „BAM-BAM“ |
| A | 5–12 (Wdh.) | Polka-Thema zum Mitsingen, 1. Mal mp, 2. Mal f |
| B | 13–28 | Es-Dur: Tuba-Solo „Der Koch rührt um!“, dann Tenorhorn-Duett in Terzen |
| Echo | 29–36 | Schnupper-Echo: Thn 1 → Thn 2 → Tuba, dann alle mit Crescendo |
| A' | 37–44 | Thema tutti in Terzen, forte |
| Coda | 45–51 | „Gu-ten Ap-pe-tit“ (allargando) – alle rufen „Mahlzeit!“ – Schlussakkord |

Umfang (notiert): Tenorhorn 1 E4–E5 · Tenorhorn 2 D4–D5 · Tuba (klingend) B1–C3 · nur Achtel und Viertel.

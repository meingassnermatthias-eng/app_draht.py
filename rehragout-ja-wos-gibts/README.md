# Rehragout – Ja wos gibt's denn heut auf d'Nacht

Satz für 2 Tenorhörner in B (Violinschlüssel) und F-Tuba, für Jungmusiker.
Melodie und 2. Stimme nach der Vorlage von www.franzdorfer.com (dort in C-Dur).

Klingend F-Dur → Tenorhörner notiert G-Dur (Thn 1 bis D5), Tuba F-Dur (C2–C3) · 2/4

| Teil | Was passiert |
|------|--------------|
| Intro | Tuba „fragt“ mit einem Lauf nach oben, Tenorhörner antworten mit dem Schluss-Motiv |
| Strophe 1 | Melodie Thn 1, 2. Stimme Thn 2 wie in der Vorlage, Polka-Bass in der Tuba; mit Wiederholung (1./2. Schluss) |
| Strophe 2 | Die Tuba spielt die Melodie (Solo!), Tenorhörner Nachschlag piano |
| Echo | „a Rehragout“ wandert: Thn 1 (f) → Thn 2 (mf) → Tuba (p) → alle (ff) |
| Strophe 3 | „Schneller!“ tutti, 1. Mal f, 2. Mal ff |
| Schluss | alle rufen „A Rehragout!“ – Schlussakkord |
